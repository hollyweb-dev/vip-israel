# Israel Concierge - Премиальная WordPress-тема

Элегантная WordPress-тема для премиальных консьерж-услуг в Израиле с темной цветовой схемой и золотыми акцентами.

## Описание

**Israel Concierge** — это полнофункциональная WordPress-тема, специально разработанная для компаний, предоставляющих VIP-услуги персонального ассистента, консьержа и управления недвижимостью в Израиле.

### Особенности

- ✨ Премиальный дизайн с темной цветовой палитрой
- 🎨 Золотые акценты и изящная типографика (Playfair Display + Inter)
- 📱 Полностью адаптивный дизайн (мобильные, планшеты, десктоп)
- 🚀 Плавные анимации при скролле
- 📧 Встроенная контактная форма с AJAX
- 🎯 7 специализированных шаблонов страниц
- ⚙️ Настройки через WordPress Customizer
- 🔒 Безопасность и производительность

## Установка

### Способ 1: Через WordPress Админ-панель

1. Упакуйте папку `israel-concierge-theme` в ZIP-архив
2. Войдите в админ-панель WordPress
3. Перейдите в **Внешний вид → Темы → Добавить новую**
4. Нажмите **Загрузить тему**
5. Выберите ZIP-файл и нажмите **Установить**
6. После установки нажмите **Активировать**

### Способ 2: Через FTP

1. Загрузите папку `israel-concierge-theme` в `/wp-content/themes/`
2. Войдите в админ-панель WordPress
3. Перейдите в **Внешний вид → Темы**
4. Найдите тему **Israel Concierge** и нажмите **Активировать**

## Настройка темы

### 1. Настройка главной страницы

1. Создайте новую страницу: **Страницы → Добавить новую**
2. Назовите её "Главная"
3. В разделе **Атрибуты страницы** выберите шаблон **Главная страница**
4. Опубликуйте страницу
5. Перейдите в **Настройки → Чтение**
6. Выберите **Статическая страница** и укажите созданную страницу

### 2. Создание страниц услуг

Создайте следующие страницы с соответствующими шаблонами:

- **Консьерж-услуги** → Шаблон: "Консьерж-услуги" → URL: `/concierge/`
- **Управление недвижимостью** → Шаблон: "Управление недвижимостью" → URL: `/property/`
- **Медицинское сопровождение** → Шаблон: "Медицинское сопровождение" → URL: `/medical/`
- **Юридические услуги** → Шаблон: "Юридические и административные услуги" → URL: `/legal/`
- **Поддержка семьи** → Шаблон: "Поддержка семьи" → URL: `/family/`
- **Контакты** → Шаблон: "Контакты" → URL: `/contact/`

### 3. Настройка меню

1. Перейдите в **Внешний вид → Меню**
2. Создайте новое меню "Основное меню"
3. Добавьте созданные страницы в меню
4. В разделе **Настройки меню** отметьте **Основное меню**
5. Сохраните меню

### 4. Настройка контактной информации

1. Перейдите в **Внешний вид → Настроить**
2. Откройте раздел **Контактная информация**
3. Заполните поля:
   - **Телефон**: +972-54-2128363
   - **Email**: info@israel-concierge.com
   - **WhatsApp**: +972542128363 (без пробелов и дефисов)
   - **Telegram**: israelconcierge (username без @)
4. Нажмите **Опубликовать**

### 5. Настройка логотипа

1. Перейдите в **Внешний вид → Настроить → Идентичность сайта**
2. Нажмите **Выбрать логотип**
3. Загрузите ваш логотип (рекомендуемый размер: 300×100px)
4. Нажмите **Опубликовать**
